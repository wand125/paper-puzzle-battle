# Puzzle Battles

Two-player games played on the solution sets of logic puzzles, and papers that solve them.
In each game the players narrow down the solutions of a puzzle; the player who leaves exactly one solution wins.

ロジックパズルの解の集合で遊ぶ 2 人対戦ゲームと、それを解いた論文の置き場です。
